## 使用范围

- 图中的单板名称、COM 端口、电源通道和本机路径为示例，按实际设备选择。
- 主线烧录页显示 T736 名称和 USB 未检测到，仅用于说明选项位置，不代表 T153 已识别或本次烧录成功。
- 新建单板和电源配置页显示默认厂商烧录路线；本项目实际选择主线 Linux、完整 raw 与独立 933 MHz FES。
- Linux 与 LuCI 截图包含早期 25.12-SNAPSHOT / Linux 6.12.113，不替代当前 25.12.6 / Linux 6.12.112 的验收记录。
